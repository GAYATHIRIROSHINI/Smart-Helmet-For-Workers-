# Project Documentation

## Project Title
Smart Safety Helmet

## Controller
ESP32

## Simulation Platform
Wokwi

## Sensors and Components
- LDR / Light Sensor
- IR Sensor
- LED / Headlight
- Buzzer
- ESP32

## Prototype
3D-Printed Smart Safety Helmet

## Project Description
The Smart Safety Helmet is an IoT-based wearable safety system designed to provide automatic lighting and sensor-based safety alerts.

The ESP32 processes the sensor inputs and controls the headlight and buzzer according to the detected conditions.

## Current Features
- Automatic headlight control using LDR
- IR-based detection
- Buzzer alert
- ESP32-based control
- Wokwi simulation
- 3D-printed prototype

## Future Improvements
- Gas detection
- Fall detection
- GPS tracking
- SOS alert
- Temperature and humidity monitoring
- Mobile application
- Wireless communication
